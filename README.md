# Audio Player
Open-source audio player with wide-range codec support

### Project Layout

  * `v2/`: the loadable extension (manifest.json, worker.js, data/)
  * `dev/`: development material that is not shipped with the extension (decoder wasm source and build script, icon sources, component notes)

### Components

  * List View: https://webextension.org/custom-component/list-view/index.html
